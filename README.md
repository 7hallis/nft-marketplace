# Kurio — NFT Marketplace

Marketplace de NFTs desenvolvido com React e TypeScript, baseado em um layout do Figma.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- TanStack Router
- TanStack Query
- Axios
- MSW
- Playwright

## Funcionalidades

- [x] Interface baseada no Figma
- [x] Pesquisa de NFTs por nome e identificador
- [x] Filtro de NFTs por faixa de preço
- [x] Filtro por categorias: todos, novos lançamentos e em alta
- [x] Paginação funcional
- [ ] Testes automatizados
- [ ] Validação de desempenho e acessibilidade com Lighthouse

## Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

```bash
npm install
```

### Ambiente de desenvolvimento

```bash
npm run dev
```

O Vite disponibilizará o endereço local no terminal.

## Objetivo

Desenvolver uma interface de marketplace de NFTs com foco em fidelidade ao design do Figma, organização do código, experiência do usuário, responsividade e qualidade de implementação.
